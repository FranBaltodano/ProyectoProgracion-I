# Cómo Jugar

## Descripción del juego
Juego de cartas con clases Baraja, Carta y Mano.

## Paso a paso
1. El programa inicia y son 6 mazos con 52 cartas cada uno
2. Se mezclan las cartas
3. Cada jugador recibe una mano de 5 cartas
4. El jugador puede pedir cartas o plantarse
5. Gana el que tenga la mejor combinación

## Controles
- Seguir las instrucciones en pantalla
- Ingresar opciones por teclado
